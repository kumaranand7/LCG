# 🚀 LinkedIn Cover Generator (LCG)

Create stunning, professional LinkedIn cover banners in seconds.  

🔗 Live Demo: https://lcg-blush.vercel.app/

--- 

## ✨ Features

- 🎨 Multiple Professional Templates
- 🖊️ Custom Name & Role Editing
- 🎯 Skills Highlight Support
- 🎨 Color Customization (Name / Role / Skills)
- ⚡ Real-time Preview
- 📥 One-click Download (PNG format)

---

## 🛠️ Tech Stack

### Frontend
- React.js
- CSS3 
- Responsive Grid Layout
- html2canvas (for image export)

### Backend
- REST API architecture
- Environment-based configuration
- Input validation & structured responses

### Deployment
- Vercel (Frontend Hosting)
- Environment Variables for secure configuration

---

## 📸 How It Works

1. Enter your Name & Role
2. Add your Skills
3. Choose a Template
4. Customize Colors
5. Preview instantly
6. Download your LinkedIn banner
